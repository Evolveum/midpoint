== 4.12-M1

=== 2026-11-19 REST API and most actuator endpoints disabled by default

Task: https://support.evolveum.com/wp/12960[12960]

Description:

The REST API is disabled by default.
Only the _health_ actuator endpoint is enabled by default.
Requests to a disabled endpoint end with HTTP 404 (Not Found) before authentication.
The intra-cluster REST endpoints (`/ws/cluster`) do not depend on the REST API.
Their default state depends on the environment: they are enabled when midPoint runs as a multi-node cluster and disabled when it runs as a single node.
To enable or disable them explicitly, set the `midpoint.rest.cluster.enabled` startup option to `true` or `false`.

Required upgrade steps:

- If you use the REST API, set the `midpoint.rest.api.enabled` startup option to `true`.
- If you use actuator endpoints other than _health_, enable them by the `midpoint.actuator.<endpoint>.enabled` or `midpoint.actuator.all.enabled` startup options.
- In a multi-node cluster, make sure that the `midpoint.rest.cluster.enabled` startup option is not set to `false`, otherwise the nodes cannot communicate with each other.
