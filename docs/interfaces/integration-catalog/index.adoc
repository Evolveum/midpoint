This section describes the Integration catalog, a standalone collection of integration methods that you can use to connect your applications, such as LDAP servers, to midPoint.

== Introduction

The Integration catalog (IC) serves as a readily available library of integration methods that allow you to connect midPoint with your target applications using xref:/connectors/[connectors] that are part of the individual integration methods.

The catalog is available at link:https://integrations.evolveum.com[https://integrations.evolveum.com] and has the following major levels:

* *Applications* - The target application or application type that you are connecting to midPoint, such as LDAP server, Google Apps, or Open Project.
Each application can be connected to midPoint through one or more different _integration methods_.
* *Integration methods* - Wrappers that define using which protocols, such as SCIM or REST API,  applications are integrated and contain one or more _connectors_.
* *Connectors* - The actual connector binaries that connect to target application.
These are modules that you upload into midPoint and configure them to integrate the target application as intended.

[[permissions]]
== User permissions

The catalog features available to you depend on your permissions level.
Some features are available to users without having to log in but some require logging in, or even elevated permissions.
You can access Integration catalog using your Evolveum environment user credentials.

The catalog features that are available to you are based on your permissions:

* Not logged in - You can browse the Integration catalog (IC) and download integration methods even if you do not log into the catalog.
* Standard logged-in user - In addition to browsing and downloading integration methods, you can request adding of integrations of applications that you have not found in the catalog.
* Contributor permissions (individual or organization) - You can submit new applications and integration methods to the catalog.


== Support tiers

Integration catalog integration methods are assigned to support tiers.
The support tier determines which integration methods are covered by your support subscription.

A subscription covers the integration methods assigned to its own tier and to all lower tiers:

* Standard covers Standard integration methods.
* Advanced covers Standard and Advanced integration methods.
* Premium covers Standard, Advanced, and Premium integration methods.

To see the complete list of integration methods based on their support tiers:

. Click btn:[Support tiers] to the right of the search field on the Integration catalog landing page.

+
image::ic-support-tiers-landing-page.webp["Integration methods classified by support tiers"]

. Click any of the btn:[All], btn:[Standard], btn:[Advanced], or btn:[Premium] buttons to see the integration methods assigned to the respective support tier.
