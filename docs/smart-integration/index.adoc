== Overview

Smart Integration provide AI-assisted and automated capabilities for resource configuration and data integration in midPoint, including:

* Smart recommendations of resource configuration (object types, focus type, correlation, mappings, associations, synchronization)
* Supporting functions used by the recommendations (schema match, statistics, shadow sampling)
