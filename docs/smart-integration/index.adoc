== Overview

Smart Integration provide AI-assisted and automated capabilities for resource configuration and data integration in midPoint, including:

* Smart recommendations of resource configuration (object types, focus type, correlation, mappings, associations, synchronization)
* Supporting functions used by the recommendations (schema match, statistics, shadow sampling)

== Recommendations

* xref:recommendations/index.adoc[Smart recommendations] - Overview of recommendation operations (object types, focus type, correlation, mappings, associations, synchronization) and their common principles.
** xref:recommendations/object-types/object-types-recommendation.adoc[Smart object types recommendation] - How midPoint recommends object types (kind, intent, delineation, focus type) for an object class from its statistics, filter validation, retry and regeneration.
** xref:recommendations/focus-type/focus-type-recommendation.adoc[Smart focus type recommendation] - How midPoint recommends the focus type (for example `UserType` or `RoleType`) for an object type from the object class schema with the help of the AI microservice.
** xref:recommendations/correlation/correlation-recommendation.adoc[Smart correlation recommendation] - How midPoint recommends single-item correlators for known identifying properties from the schema match and existing inbound mappings, and how their quality is evaluated on sampled data.

** xref:recommendations/mappings/mappings-recommendation.adoc[Smart mappings recommendation] - How midPoint recommends inbound and outbound attribute mappings (as-is, heuristic, AI-generated and categorical scripts), quality assessment and result structure.

** xref:recommendations/associations/associations-recommendation.adoc[Smart associations recommendation] - How midPoint recommends associations between configured object types from references in the resource schema without the AI microservice, including the generated inbound and outbound mappings, membership correlation and synchronization.

== Configuration

Setting relevant to Smart Integration are configured globally in the midPoint system configuration (`SystemConfigurationType`) within the `<smartIntegration>` container.

* xref:configuration.adoc[Smart Integration configuration] - All settings of the `<smartIntegration>` container: microservice connection, reuse of statistics and schema matches, mapping retries, shadow sampling and connector generator.
